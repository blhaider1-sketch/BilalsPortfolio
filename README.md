The supplied screenshots for Bloody Malta and Interiors & Living are included in `public/projects/`. The OpsPeoples preview is a stylized interface placeholder; visit the live website for the actual product.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the framework preset as **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.
